Tentang Saya

Halo, perkenalkan nama saya Mikaylo Andza. Saya adalah siswa kelas 11B yang sedang belajar membuat website sederhana menggunakan HTML dan CSS.

Website ini dibuat sebagai salah satu tugas TIK sekaligus latihan untuk memahami cara membuat tampilan web yang rapi, menarik, dan mudah digunakan.

Di dalam website ini terdapat beberapa halaman seperti Home, About, Contact, dan Gallery yang dibuat dengan desain sederhana namun tetap nyaman dilihat.

Pengalaman Belajar

Saya belajar mulai dari membuat struktur HTML, mengatur warna background, menambahkan gambar profil, membuat navbar, hingga memberi efek hover pada menu navigasi.

Saya juga belajar bagaimana cara menggunakan CSS untuk mempercantik tampilan website seperti memberi border, shadow, warna gradasi, dan layout yang lebih rapi.

Awalnya cukup sulit memahami coding, tetapi lama-kelamaan saya mulai terbiasa dan semakin tertarik untuk belajar lebih dalam.

Harapan Saya

Selain untuk tugas sekolah, saya juga ingin mengembangkan kemampuan dalam bidang coding dan desain web agar nantinya bisa membuat website yang lebih keren dan modern.

Saya berharap website sederhana ini dapat menjadi awal yang baik untuk terus belajar teknologi dan pemrograman web di masa depan.

Terima kasih sudah berkunjung ke website saya. Jangan lupa untuk melihat halaman About, Contact, dan Gallery juga ya!
